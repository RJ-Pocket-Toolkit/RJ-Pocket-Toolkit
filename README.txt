RJ Pocket Toolkit - Website

GitHub Pages:
1. Create/open a GitHub repository.
2. Upload EVERYTHING inside this website folder.
3. Settings -> Pages -> Deploy from branch -> main -> / (root).
4. Save and open the generated Pages URL.

The website is fully browser-based and includes the professional invoice,
logo/signature upload, print/save PDF, GST, percentage, age, date difference,
unit, password, text, number-to-words, storage, random and WhatsApp tools.
